# Working memory — skeleton content for initial files

Use these skeletons as the *initial* content of `decisions.md` and
`open-questions.md` when scaffolding. Do not merge them into a single
file — they have different lifecycles.

---

## decisions.md — initial content

```markdown
# Decisions

Append-only log of decisions taken on this case. Newest entries at
the top. Never edit the substance of a prior entry — if a decision
is reversed, write a new entry and add a `**Superseded by:**` line
to the original pointing at the new one. Benign edits (typos,
formatting fixes) are permitted in place.

---

*No decisions recorded yet.*
```
